# bowspa 주간 근무 스케줄표

`schedule.bowspa.kr` 에 올리는 정적 페이지 + 아주 작은 저장 API.

```
index.html        스케줄표 본체 (브라우저에서 바로 열어도 동작)
api/schedule.js   Vercel 서버리스 함수 — Turso 읽기/쓰기
schema.sql        Turso 에 한 번만 실행할 테이블 정의
```

## 배포에 필요한 환경변수 (Vercel)

| 이름 | 값 |
|---|---|
| `TURSO_DATABASE_URL` | `libsql://<db이름>-<계정>.turso.io` |
| `TURSO_AUTH_TOKEN`   | `turso db tokens create <db이름>` 로 만든 토큰 |

토큰은 서버(함수)에만 있고 브라우저로 내려가지 않습니다.

## 동작 방식

- 입력하면 **먼저 브라우저에 저장**해서 화면이 끊기지 않고, 0.6초 모아 서버로 한 번 올립니다
- 주차를 바꾸면 그 주 데이터를 서버에서 받아옵니다 (서버 값이 우선)
- 서버에 못 닿으면 `오프라인` 으로 표시되고 이 브라우저에만 저장됩니다
- `index.html` 만 따로 열어도(더블클릭) 오프라인 모드로 그대로 쓸 수 있습니다

## 주의

접근 제한이 없습니다. 주소를 아는 사람은 누구나 근무표를 보고 고칠 수 있습니다.
필요해지면 공용 비밀번호를 거는 데 오래 걸리지 않습니다.
